# Maquette du site vitrine, CENTURY 21 Azur

Maquette de travail réalisée par R Design Belgium pour l'agence CENTURY 21 Azur (Koekelberg, Bruxelles). Ce n'est pas le site officiel de l'agence.

- `index.html` : page d'accueil, HTML et CSS sans dépendance autre que Google Fonts.
- `assets/` : illustrations fictives, à remplacer par les photos de l'agence.

Les six biens affichés ont été relevés sur century21.be le 27 novembre 2026. Les contenus entre crochets (logo, équipe, avis, horaires, mentions légales) sont à fournir par l'agence.

Le formulaire de contact n'envoie rien : il sert uniquement à illustrer la mise en page.
